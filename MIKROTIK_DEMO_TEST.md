# MikroTik Demo / Test Mode

1. Open Network / OLT -> MikroTik Dashboard.
2. Click Enable Demo / Test Mode.
3. Demo data works without a physical MikroTik and without the adapter running.
4. All MikroTik sections use sample data in demo mode.
5. To return to a real router, open MikroTik Router Settings and select Real MikroTik.
